# My Custom Weather

This project is built using VueJS 3, Vite and SCSS.

**It is recommended to use node version 19**

## Requirements

- Display the weather conditions for the following cities:

1. Joinville / SC (Brazil)
2. San Francisco / CA (USA)
3. Urubici / SC (Russia)

- Temperature should be displayed in **Celsius**
- Humidity should be displayed as a **percentage**
- Pressure should be displayed

- Temperature color coding conditions:

1. 5°C or below -> Blue
2. Above 5°C and up to 25°C -> Orange
3. Above 25°C -> Red

- Weather conditions must **update every 10 minutes**

## Recommended IDE Setup

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur).

## Project Setup

```sh
npm install
```

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
